

# CinemaTicket — Etapa 3

## Descriere

CinemaTicket este o aplicație pentru gestionarea vânzărilor de bilete la cinema. Proiectul este dezvoltat în cadrul laboratorului de Tehnologii Web.

## Tehnologii

- React
- JavaScript
- Vite
- CSS

## Structura proiectului

- `src/App.jsx` — componenta principală și datele despre bilete.
- `src/App.css` — stilurile aplicației.
- `src/main.jsx` — punctul de intrare React.
- `index.html` — documentul HTML principal.

## Funcționalități implementate în Etapa 3

- Afișarea numelui aplicației CinemaTicket.
- Afișarea numărului total de bilete.
- Calcularea numărului de bilete disponibile.
- Afișarea listei de bilete în format JSON.
- Utilizarea React și Vite pentru dezvoltare.

## Rulare locală

Din folderul `frontend`, execută:

```bash
npm install
npm run dev
```

Pentru verificarea build-ului:

```bash
npm run build
```
